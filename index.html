How to install your extension

Follow these steps to add your extension to your browser. It only takes a minute — no technical experience needed.

  1. Download the ZIP and save it somewhere easy to find

    Click Download ZIP above. When your browser asks, save the file somewhere you'll remember — your Downloads or Desktop folder works well.

  2. Unzip (extract) the folder

    On Windows: right-click the ZIP file and choose Extract All…, then confirm.
    On Mac: just double-click the ZIP file — it unzips on its own.

    You'll end up with a regular folder of the extension's files.

  3. Open your browser's Extensions page

    In Chrome, click the address bar, type chrome://extensions, and press Enter.

    In Edge, click the address bar, type edge://extensions, and press Enter — or open the … menu → Extensions → Manage extensions.

  4. Turn on Developer mode, then click "Load unpacked"

    Switch on Developer mode (the toggle is in the top-right cornerin the bottom-left corner). A new Load unpacked button appears — click it.

  5. Select the folder you just extracted

    In the file picker, choose the extracted folder and click Select Folder (Windows) or Open (Mac). That's it — your extension is installed and ready to use.

  6. Pin it to the toolbar Optional

    Click the puzzle-piece icon near the top-right of your browser, find your extension, and click the pin so it's always one click away.

Only load extensions you trust — an unpacked extension runs with all the permissions it requests.
